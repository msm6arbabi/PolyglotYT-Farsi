# PolyglotYT-Farsi

نسخه اصلاح‌شده PolyglotYT با پشتیبانی از زبان فارسی و زبان‌های بیشتر.

## ✨ زبان‌های اضافه شده:
- **فارسی (Persian)** 🇮🇷
- العربية (Arabic)
- Türkçe (Turkish)
- Português (Portuguese)
- Italiano (Italian)
- Hindi
- اردو (Urdu)
- پښتو (Pashto)

## 📱 نصب:
1. فایل APK رو از [Releases](../../releases) دانلود کن
2. نصب کن
3. LSPosed Manager → PolyglotYT → فعال کن برای YouTube
4. ری‌استارت یوتیوب

## ⚙️ تنظیمات:
1. در یوتیوب → Settings → PolyglotYT
2. زبان مقصد رو روی **فارسی** تنظیم کن
3. سرویس ترجمه رو انتخاب کن (Google Translate پیشنهاد می‌شه)

## 🔧 ساخت از سورس:
```bash
git clone https://github.com/YOUR_USERNAME/PolyglotYT-Farsi.git
cd PolyglotYT-Farsi
./gradlew assembleDebug
```

APK در `app/build/outputs/apk/debug/` ساخته می‌شه.
